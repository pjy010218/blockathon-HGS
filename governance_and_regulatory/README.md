# Governance and Regulation

Blockchain@UBC Summer Institute 2026 · Blockathon for Social Good.

- **[guidelines.md](guidelines.md)** — rules to build by. Read before writing code.
- **[checklist.md](checklist.md)** — 14 questions to answer as a team.

Build the mechanism, don't launch the market. Protocols and cryptography are
essentially unregulated to build and to study; you cross into regulated territory
when real, external value starts flowing. This week: testnet only, no tradeable
token, no outside deposits, no yield.

Nobody expects a licence by Saturday. What matters is that the regulatory and
privacy consequences of the design were **choices we made, not accidents we
discovered.**
